# Frame Heart

![The Frame Heart window, with a before and after viewer](https://inigo-code.github.io/frame-heart-site/assets/remove-wide.webp)

Website and downloads for Frame Heart, one of the [Heart Apps](https://inigo-code.github.io/). It works particularly well on images and videos made with Gemini. Download the app from [Releases](../../releases/latest).

The site is plain HTML and CSS, served by GitHub Pages. heart.css and heart.js are the shared Heart Apps files. The apps are free, all rights reserved.
